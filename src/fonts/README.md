# Local typefaces

Fraunces, Inter and JetBrains Mono are served from this directory with their bundled licences. No font host is contacted by the browser.

`fraunces-og.ttf` is a static instance of `fraunces-latin-variable.woff2`, generated with fontTools at optical size 72 and weight 400. The remaining Fraunces axes are pinned to their defaults and all variation tables are removed because the server image renderer does not support variable-font metadata. It is used only by the server's image renderer. The existing Fraunces licence also covers this derived instance. Browser typography uses the variable WOFF2 with its `opsz` (9–144) and `wght` (100–900) axes retained. Phase 6 pins the unused `SOFT` and `WONK` axes to their original defaults (0 and 1) using fontTools, reducing transfer size without changing their appearance. `src/app/icon.svg` contains outlined `pc` glyphs derived from the same licensed font at optical size 72 and weight 300. JetBrains Mono remains self-hosted and loads when used rather than competing with the first heading via preload.
