# Test Plan
Generated by /plan-eng-review on 2 October 2026
Branch: main
Repo: local-only

## Affected Pages/Routes
- /services and /services/page/2: selected A design, truthful empty state, real rows, audience text and pagination.
- /training and /training/page/2: selected A design, upcoming/archive separation, sold-out/cancelled/past labels, dates/timezones and pagination.
- /about: selected A (prior B), editable biographies, named portrait spaces, genuine portraits and ordered custom blocks.
- Home, Journal, contact and other CMS pages: shared rendering/theme regression checks.

## Key Interactions to Verify
- Follow enquiry, About, product and actual catalogue detail links; back navigation and pagination remain native and useful.
- At phone widths Training text/action comes before the photograph; About portrait precedes each biography in reading order.
- Keyboard traverses menus and actions with visible focus; skip link works; theme changes persist.
- Verify 390/768/1440px, dark/light, reduced motion and 200% zoom. No horizontal clipping or hidden content.
- Check compressed local assets, reserved image space and real-media alt/caption/credit.

## Edge Cases
- Zero/one/many Services; long title, blank/optional summary and audience, unsafe link, draft result.
- Training with missing/invalid date, invalid timezone, sold-out upcoming, archive only and later page where upcoming is empty.
- No/one/many founders, two separated founder groups, custom block between biographies, no leading hero, later hero, rich text/links.
- Portrait absent, numeric ID, placeholder flag, invalid metadata, genuine portrait and failed HTTP request. No PLACEHOLDER 10 or fake person.
- Failed required listing/page read uses the public error state, not a false empty message.
- Invalid pagination gives 404; explicit page one redirects; metadata follows canonical route.

## Critical Paths
- Render all selected content in the initial server HTML; exactly one h1.
- Preserve every custom About block and its original order; preview and public render independently.
- In an isolated fixture, apply approved About content: backup then update; second invocation no-op; changed/draft/custom content refuses; backup failure forbids writes.
- Verify content publication and dependent outputs refresh within 60 seconds after commit through the existing job worker. Do not rebuild to mask stale cache.
- Anonymous requests never display staff draft data; preview response must remain private/no-store.
- Do not publish sample service/event records in the user's database. Isolated fixtures must be restored.
- Run pnpm lint && pnpm typecheck && pnpm test && pnpm build after each implementation return; independent reviewer and re-review after fixes; browser/performance checks before acceptance.
