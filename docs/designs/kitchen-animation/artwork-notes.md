# Character artwork provenance

Final project asset: `assets/people-v3.webp` (1536 × 1024, alpha preserved).

Created with the built-in image-generation tool. Original generated file: `exec-0f2c562b-0b47-4bbe-a7f3-cf8d80071235.png`. The generated PNG already contains transparency; WebP conversion retained its alpha. A later background-extraction variant was inspected but not used. Browser SVG viewports select the three figures, and a clipped copy of the chef's working forearm supports movement without deforming the face.

These are fictional illustrated people, not founder portraits, customer photographs or endorsements. The existing kitchen background remains the generated concept setting from study 02. The reference request sent to image generation contained no company name or private business information.

Style: sophisticated hand-painted European editorial illustration, fine gouache and watercolour modelling, subtle warm light from left, gently textured fabric, believable anatomical proportions, refined realistic faces and five-finger hands.
